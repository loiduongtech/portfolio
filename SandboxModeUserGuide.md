# Sandbox Mode — Quick Guide

Sandbox is a **free decorate room** for testers. No challenge, timer, score, or Submit.

## Open Sandbox

Main Menu → tap **Sandbox** (not Start Game).

## Extra buttons (Sandbox only)

- **Capture** — saves 2 files: a **PNG** (photo) and a **JSON** (room data)
- **Load** — opens a saved `.json` and rebuilds that room (replaces current decorations)
- **Reset** — empty room again
- **Home** — back to Main Menu

Load / Reset / Home will ask you to confirm first.

## Send a room to a developer

1. Decorate the room.
2. Tap **Capture**.
3. Send **both** files from the same Capture (same time in the name), e.g.  
   `utopic_room_20260808_123045.png` + `utopic_room_20260808_123045.json`

Do not edit the JSON. The PNG is for looking; the JSON is for the developer to Load.

## Notes

- Closing the browser or going Home does **not** keep the room unless you Captured it.
- If only one file downloads, allow downloads in the browser and Capture again.
- To reopen a room: Sandbox → **Load** → pick the `.json` (not the PNG).
