Sandbox Mode

A free decorate room for testers. No challenge, timer, score, or Submit — just build the room you want.

Quick to use · Easy to share

Getting started

Open Sandbox

From the Main Menu, choose Sandbox instead of Start Game.

Main Menu
→
Sandbox

Sandbox controls

Four simple actions

These buttons are available only while you are in Sandbox Mode.

↓

Capture

Saves two files: a PNG photo and a JSON file containing the room data.

↥

Load

Opens a saved .json file and rebuilds that room, replacing the current decorations.

↺

Reset

Returns the room to an empty state so you can start again.

⌂

Home

Returns you to the Main Menu.

Load, Reset, and Home will ask you to confirm first.

Sharing a room

Send your room to a developer

Capture the room once, then send both files created by that same capture.

1
Decorate the room

Build the layout you want to share.

2
Tap Capture

Sandbox will save a PNG and a JSON file.

3
Send both matching files

Use the pair with the same time in the filename.

utopic_room_20260808_123045.png
utopic_room_20260808_123045.json
Important: Do not edit the JSON. The PNG is for looking at the room; the JSON is what the developer uses to Load it.

Good to know

A few quick notes

✓

Closing the browser or going Home does not keep the room unless you Captured it.

✓

If only one file downloads, allow downloads in the browser and Capture again.

✓

To reopen a room: Sandbox → Load → choose the .json file, not the PNG.
